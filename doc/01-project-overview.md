# Project Overview

## Project Name
Futy League Management Admin Panel

## Description
This project is built using Next.js 15 for admin management and API handling.

## Main Features

- Admin authentication
- League CRUD
- Team management
- Manager management
- Pagination
- Search & filters
- File uploads
- Role-based access
- REST APIs

## Technologies Used

- Next.js 15
- React 19
- MongoDB
- Mongoose
- Zod Validation
- Bootstrap CSS
- JWT Authentication
