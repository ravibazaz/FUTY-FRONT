# Installation Guide

## Requirements

- Node.js 22+
- MongoDB
- npm or pnpm

## Clone Repository

```bash
git clone https://github.com/your-project/admin.git
```

## Install Packages

```bash
npm install
```

## Environment Setup

Create `.env.local`

```env
MONGODB_URI=
JWT_SECRET=
NEXT_PUBLIC_API_URL=
```

## Run Development Server

```bash
npm run dev
```
